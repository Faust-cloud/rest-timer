## Features

- 👆 **Tap the ring** to start / pause
- 🔄 **Drag around the ring** to set any duration (5s – 5:00)
- ⚡ **Quick presets:** 1 min & 3 min
- 🔢 **Set counter** — tracks your current set, auto-increments each round
- 🎨 **Color-coded ring** — glows warm, turns red in the final 10 seconds
- 🔔 **Sound** — soft 3-2-1 countdown + gentle chime at the end (toggleable)
- 💡 **Keeps the screen awake** while running
- 📴 **Works offline** once added to your home screen
- 🌙 **Dark cinematic design** with film-grain texture and a serif display

## Usage

1. Open the link in **Safari** on your iPhone
2. **Share** → **Add to Home Screen**
3. Launch from the icon for a full-screen, app-like experience

**Keyboard (desktop):** `Space` start / pause · `R` reset

## Tech

A single self-contained `index.html` — no frameworks, no build step, no dependencies. Vanilla JS + SVG + Web Audio API + Screen Wake Lock API. Hosted free on GitHub Pages.

一个极简、带电影感的**健身组间休息计时器**。点一下开始,拖动设时长,结束时有温暖的提示音。

**在线使用:** https://faust-cloud.github.io/rest-timer/

**功能**
- 点圆环 开始 / 暂停
- 沿圆环拖动设任意时长(5 秒 – 5 分钟)
- 快捷预设:1 分钟 / 3 分钟
- 组数计数,每组结束自动 +1
- 进度环变色:平时暖色,最后 10 秒转红
- 3-2-1 倒数提示音 + 结束钟琴声(可关)
- 计时中屏幕常亮
- 加到主屏后可离线使用

**用法:** iPhone 用 Safari 打开链接 → 分享 → 添加到主屏幕 → 从图标全屏打开。
