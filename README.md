# Rest Timer

A minimal, cinematic rest timer for between your gym sets. Tap to start, drag to set, and get a warm chime when time's up.

**Live:** https://faust-cloud.github.io/rest-timer/

## Features

- **Tap the ring** to start / pause
- **Drag around the ring** to set any duration (5s–5:00)
- **Quick presets:** 1 min and 3 min
- **Set counter** with +/− to track which set you're on (auto-increments each round)
- **Color-coded ring** — glows warm, turns red in the final 10 seconds
- **Sound** — soft 3-2-1 countdown beeps and a gentle chime at the end (toggle on/off)
- **Keeps the screen awake** while a timer is running
- **Works offline** once added to your home screen
- **Auto dark cinematic design** with film-grain texture and a serif display

## Usage

1. Open the live link in **Safari** on your iPhone.
2. Tap the **Share** button → **Add to Home Screen**.
3. Launch it from the home-screen icon for a full-screen, app-like experience.

### Keyboard (desktop)

- `Space` — start / pause
- `R` — reset

## Tech

A single self-contained `index.html` — no frameworks, no build step, no dependencies. Built with vanilla JavaScript, SVG, the Web Audio API, and the Screen Wake Lock API. Hosted free on GitHub Pages.
